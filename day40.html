03 · Full Journey

Một hành trình từ đường phố → ga → tàu → taxi

Nghe lần 1 không nhìn text. Lần 2 bắt: place → direction → platform → train → ticket → taxi → time.

05 · Follow Directions

Nghe route bằng action chunks

まっすぐ行きます。

= Đi thẳng.

右に曲がります。

= Rẽ phải.

左に曲がります。

= Rẽ trái.

次の角を右に曲がります。

= Rẽ phải ở góc tiếp theo.

💡 Route decoding STRAIGHT → LANDMARK → TURN → DESTINATION
06 · Inside the Station

Gate → platform → track

改札はどこですか。

= Cổng soát vé ở đâu?

何番線ですか。

= Platform số mấy?

三番線です。

= Platform 3.

⚠ Platform number ≠ floor number 三番線 = platform/track 3
三階 = tầng 3
07 · Choose the Train

Check before boarding

= Tàu đi Shinjuku ở platform mấy?

違います。次の電車です。

= Không phải. Là chuyến kế tiếp.

🇯🇵 Boarding safety check destination → platform → current train.

13 · Sentence Repair

Sửa 8 lỗi hay gặp

✕ 駅は何ですか。 → ✓ 駅はどこですか。

Location phải dùng どこ.

✕ 右を曲がります。 → ✓ 右に曲がります。

Direction + に.

✕ 何線番ですか。 → ✓ 何番線ですか。

Whole chunk: 何番線.

✕ どれ電車ですか。 → ✓ どの電車ですか。

どの + noun.

✕ 東京の切符まで。 → ✓ 東京までの切符。

Endpoint phrase + の + noun.

✕ ここまでお願いします。〔stop now〕 → ✓ ここでお願いします。

“Dừng ở đây” dùng ここで.

✕ 三十分ぐらいかかりますか。〔answer〕 → ✓ 三十分ぐらいです。

Answer estimate đơn giản bằng です.

✕ 電車まで三十分です。 → ✓ 電車で三十分ぐらいです。

Means of transport dùng で.
