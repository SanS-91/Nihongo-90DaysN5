Day 27 · Food & Shopping

サイズと色いろ

Sizes & Colors
Mua quần áo/túi/giày thực tế hơn: hỏi màu → hỏi size → hỏi còn không → chọn → mua.
N5 Beginner 65–80 phút 何色ですか Mサイズはありますか 赤い / 黒い Shopping survival
Mục tiêu hôm nay

Sau bài này, bạn có thể hỏi 何色ですか。, hỏi còn size bằng Mサイズはありますか。, nói các màu cơ bản như 赤・青・白・黒, và chọn: 黒のMサイズをお願いします。

🌱 Day 27 chưa phải bài adjective Các cụm 赤いシャツ・白いシャツ・黒いバッグ・大きいサイズ được học như cụm dùng thật. Chưa cần học chia adjective đầy đủ.

04 · 何色ですか

Hỏi “màu gì?”

X は 何色ですか。

このシャツは何色ですか。 = Áo này màu gì?

色 + です

黒です。 = Màu đen.
白です。 = Màu trắng.

💡 何色 đọc là なにいろ 何（なに） + 色（いろ） → 何色（なにいろ）.
⚠ 何色 ≠ 何 これは何ですか = đây là gì?
これは何色ですか = đây màu gì?
05 · Sizes

Size trong tiếng Nhật rất quen

Sサイズ

エスサイズ · size S

Mサイズ

エムサイズ · size M

Lサイズ

エルサイズ · size L

LLサイズ

エルエルサイズ · size LL

サイズは何ですか。

= Size là gì?
Mサイズです。 = Size M.

🇯🇵 Nhật có thể dùng S / M / L / LL thay vì XS / XL kiểu bạn quen Từng brand có bảng size khác nhau. Day 27 chỉ học cách hỏi/nghe size, không suy ra kích thước cơ thể từ ký hiệu.
06 · 〜はありますか

“Có … không?” trong context hàng còn hay hết

Item / Size / Color + は ありますか。

Mサイズはありますか。 = Có size M không?
黒はありますか。 = Có màu đen không?

はい、あります。

= Vâng, có.

すみません、ありません。

= Xin lỗi, không có.

⚠ Đây là functional chunk Day 15 đã gặp 会議があります.
Hôm nay dùng Mサイズはありますか để hỏi tồn hàng.
Hệ thống あります / います sẽ học đầy đủ ở Day 46.
07 · Color + Item

Hai cách bạn sẽ gặp màu đứng trước món đồ

Color noun + の + Noun

黒のバッグ = túi màu đen.
白のMサイズ = size M màu trắng.

赤い / 青い / 白い / 黒い + Noun

Bạn cũng sẽ rất thường gặp: 赤いシャツ, 青いシャツ, 白いシャツ, 黒いバッグ.

💡 Day 27 target Productive an toàn: 黒のMサイズ.
Recognition + useful chunk: 黒いバッグ.
Chưa cần học cách chia adjective.
⚠ Không phải mọi màu đều thêm い ピンクい ✕
Với beginner, nói: ピンクのシャツ ✓
08 · Big / Small

Khi size không vừa: chỉ cần 2 từ

大きいサイズ

大きい（おおきい） = lớn.
大きいサイズ = size lớn hơn / size lớn.

小さいサイズ

小さい（ちいさい） = nhỏ.
小さいサイズ = size nhỏ.

もう少し大きいサイズはありますか。

Recognition + optional production: Có size lớn hơn một chút không?

⚠ “もう少し” chỉ học như chunk もう少し = thêm một chút / hơn một chút.
Day 27 chưa cần phân tích toàn bộ hệ so sánh.
09 · Kanji Helper

Kanji màu và shopping: học theo whole word

色いろ

màu. Trong 何色 đọc いろ → 何色（なにいろ）.

赤あか

đỏ. Từ màu cơ bản, nên nhận diện chủ động.

青あお

xanh dương. Học nguyên từ 青.

白しろ

trắng. Whole word: 白.

黒くろ

đen. Whole word: 黒.

大おおきい / 小ちいさい

lớn / nhỏ. Recognition như hai từ thực dụng.

🌱 Must recognize 色・赤・青・白・黒.
Recognition only: 大きい・小さい nếu còn mới.

18 · Today's Mission

Find the Right One — 90 seconds

Mô phỏng bạn đang mua áo hoặc túi. Mục tiêu là lấy đúng màu + size.

1. Hỏi màu.
これは何色ですか。
2. Chọn màu.
黒にします。
3. Hỏi size M.
Mサイズはありますか。
4. Hỏi thêm màu trắng.
白もありますか。
5. Chọn phiên bản chính xác.
黒のMサイズをお願いします。
6. Nếu không vừa, hỏi size lớn hơn một chút.
もう少し大きいサイズはありますか。
7. Làm lại với màu + size khác, không nhìn mẫu.
白 / 赤 / ピンク / S / L / LL...
✅ Pass standard Bạn có thể nói: màu gì → có size X không → có màu Y không → lấy đúng color + size mà không cần nhìn script.
